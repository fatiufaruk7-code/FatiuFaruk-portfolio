## 🚀 Overview

**Clarity Creative** is the digital portfolio and web development service platform of an aspiring Web Developer and Computer Science student. It showcases high-performance, responsive websites and modern digital experiences designed for businesses, organizations, and individuals.

### ✨ Key Features

- **Geometric Brand Identity**: Bespoke C² / CC monogram logo with glowing purple, blue, and cyan accents.
- **Interactive Preloader**: Fullscreen entrance animation with a smooth progress bar and instant skip accessibility.
- **Continuous Tech Marquee**: Infinite looping tech stack strip featuring HTML5, CSS3, JavaScript, React, Git, GitHub, Vercel, Firebase, and TypeScript.
- **Curated Projects Showcase**: Interactive case studies highlighting 4 core projects:
  - *Personal Portfolio Website* (Personal Project)
  - *Restaurant Website* (Demo Project)
  - *Clarity Sell* (Concept Project)
  - *School Portal* (Concept Project)
- **Modal Case Studies**: Detailed overlay views including project overviews, objectives, technical features, and stack breakdown.
- **Transparent Pricing**: Categorized tier packages (*Starter*, *Professional*, *Custom*) with clear deliverables and WhatsApp/form routing.
- **Responsive Ergonomics**: Tailored viewport layouts optimized for mobile, tablet, and desktop displays.
- **PWA Ready**: Offline caching, install banners, and service worker shell.

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/clarity-creative.git

# Navigate into the project directory
cd clarity-creative

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Compile and build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel

This repository is pre-configured for zero-config deployment on Vercel:

1. Push your repository to GitHub.
2. Import the repository in [Vercel Dashboard](https://vercel.com/new).
3. Set the Framework Preset to **Vite**.
4. Deploy!
